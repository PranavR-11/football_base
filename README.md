I built Football Analytics AI (FootballBase), a real time multilingual RAG plus LLM analytics assistant that turns sports datasets into conversational insights, charts, and exportable assets.

Why I built it. I wanted a product that combines data engineering, machine learning, and visual analytics into a single workflow so an analyst can ask a plain language question and receive a data backed answer, a chart, and an exportable slide in seconds.

How it works. The frontend is Next.js and React with Chart.js for lightweight client charts and a streaming UI. The client communicates with the backend over WebSockets so results arrive token by token. The API is FastAPI and it streams JSON and chart images generated with matplotlib. LangChain orchestrates the model work and OpenAI models handle intent classification and slot-filling to convert user language into structured tool calls. RAG is powered by FAISS plus Sentence Transformer embeddings with fuzzy matching for robust entity resolution. MCP coordinates tool invocations and data retrieval between the agent and internal services. Data wrangling uses Pandas with a small SQLite cache for fast repeatable responses. Everything is containerized with Docker and proxied with Caddy for TLS and WebSocket passthrough.

What it delivers. Concise, cited answers with inline sources, on demand charts, and PNG export. Automatic language detection enables localized answers across the top ten languages. The combination of semantic retrieval, toolified data calls, and LLM reasoning produces auditable, production ready responses.

Real world value. For research teams this means instant cited charts for investor decks. For support teams this means knowledge base assisted replies with confidence scores. For retail and CPG this means promo lift estimates and SKU recommendations. For IoT and manufacturing this means anomaly explanation plus ranked inspection checklists that speed repairs. For regulated industries this means turning long policy documents into prioritized product tasks and compliance checklists.
